# Спецификации LifeOS Agent

В этой папке находятся спецификации всех функций проекта.

## Главное правило

Новая функциональность **никогда** не реализуется сразу в коде.

Сначала создается спецификация.

Только после ее утверждения начинается реализация.

---

## Формат

Каждая спецификация хранится в отдельном файле.

Примеры:

```
specs/
├── 001-memory.md
├── 002-planner.md
├── 003-habits.md
```

---

## Каждая спецификация должна содержать

- Цель
- Бизнес-требования
- Пользовательские сценарии
- Архитектуру
- Модели данных
- API
- План реализации
- План тестирования
- Definition of Done

---

## Правило

Если нет спецификации — нет кода.

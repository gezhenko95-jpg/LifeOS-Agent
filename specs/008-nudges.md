# Nudges Specification

---

# Цель

Раз в день бот проактивно напоминает о двух вещах, которые пользователь
мог упустить: приближающийся дедлайн цели с низким прогрессом и
прервавшийся стрик привычки. Отдельно от этого — в момент отметки
привычки выполненной, при достижении круглой серии (7/30/100 дней),
бот коротко празднует это прямо в ответе.

---

# Что НЕ входит

- AI здесь не используется вообще — оба условия детерминированные
  (ADR-004: простой код там, где хватает обычных сравнений дат/чисел).
- Нет настраиваемых порогов дедлайна/обрыва стрика через `.env` — три
  жёстко заданных дня до дедлайна (3, 1, 0) и фиксированный "день после
  обрыва" (2) для стрика. Усложнять конфигурацию ради этого не стали.

---

# Условия (`app/scheduler/nudges.py::build_nudges`)

## Дедлайн цели

Для каждой активной цели с `target_date` и `progress < 100`:
`days_left = target_date - today`. Если `days_left` РОВНО ОДНО ИЗ
`{3, 1, 0}` — нэдж `"⏳ Цель «X» — дедлайн через N дн./сегодня, прогресс
P%."`.

Важно: сравнение "ровно N", а не "≤ N" — при ежедневном запуске job'ы
условие попадает под каждый порог только один раз за жизнь цели, не
спамит каждый день до дедлайна.

## Обрыв стрика привычки

Новый `HabitService.days_since_last_completion(habit_id) -> int | None`
(на основе уже существующего `list_logs`, который сортирует по
`completed_on` по убыванию — первый лог самый свежий). Если результат
РОВНО `2` — нэдж `"💔 Стрик «Y» прервался — начать заново сегодня?"`.

Почему именно 2: `HabitService.get_streak` "прощает" сегодняшний день
(см. `specs/004-habits.md`) — стрик становится 0 только когда НИ вчера,
НИ сегодня привычка не отмечена. Момент "стрик только что обнулился" —
это день, следующий за последним пропущенным (т.е. `days_since_last_completion
== 2`: последний лог позавчера, вчера и сегодня — пусто). На третий день
условие уже не сработает — не долбит уведомлениями бесконечно.

Если `build_nudges` вернул пустой список — `send_nudges_job`
(`app/telegram/jobs.py`) ничего не отправляет (как `send_task_reminders_job`,
когда нечего напомнить).

---

# Празднование вехи стрика (без job'а)

`ConversationEngine._habit_done` (`app/conversation/engine.py`): после
вычисления `streak`, если `streak in {7, 30, 100}` — к обычному ответу
("Готово: «X» — 🔥 N дней подряд.") добавляется вторая строка
`"🎉 N дней подряд — солидная серия!"`. Срабатывает сразу в момент
отметки, не требует отдельного планировщика.

---

# Планировщик

`send_nudges_job` — по образцу `send_task_reminders_job`. Регистрируется
в `app/telegram/bot.py` через `run_daily` (ежедневно, не только по
воскресеньям — в отличие от дайджеста). Настройки: `nudges_enabled`,
`nudges_hour` (9 по умолчанию), `nudges_minute` (0).

---

# Definition of Done

- `days_since_last_completion` покрыт тестами (нет логов → None, берёт
  именно самый свежий лог);
- `build_nudges` покрыт на все ветки: порог дедлайна 3/1/0, вне порогов,
  без `target_date`, завершённая цель (`progress == 100`) не нэджится
  даже на пороге, обрыв стрика ровно на 2-й день, вне этого окна, ни разу
  не отмеченная привычка, пустой список, комбинация цель+привычка;
- celebration-ветка `_habit_done` покрыта: на вехе / вне вехи.

# Memory Service Specification

---

# Цель

Memory Service отвечает за хранение всей информации о пользователе.

Это единственный источник долговременной памяти LifeOS.

Все остальные сервисы получают данные только через Memory Service.

---

# Основные задачи

Memory Service должен:

- сохранять факты;
- сохранять предпочтения;
- сохранять цели;
- хранить историю взаимодействий;
- хранить долгосрочные заметки;
- выдавать релевантный контекст по запросу.

---

# Что НЕ входит

Memory Service не:

- генерирует ответы;
- принимает решения;
- вызывает LLM;
- занимается планированием;
- отправляет сообщения пользователю.

---

# Типы памяти

## Facts

Объективные факты.

Примеры:

- имя;
- дата рождения;
- профессия;
- место работы;
- город.

---

## Preferences

Предпочтения пользователя.

Например:

- любит короткие ответы;
- предпочитает Telegram;
- использует TickTick;
- любит документальные фильмы.

---

## Goals

Текущие цели.

Например:

- похудеть;
- выучить английский;
- увеличить доход.

---

## Projects

Информация о проектах.

Например:

- LifeOS Agent
- DnD AI
- LeadEnricher

---

## Conversations

История общения.

Используется для восстановления контекста.

---

## Journal Entries

Личные записи пользователя.

---

# API

Memory Service предоставляет следующие операции.

## Save

Сохранить информацию.

---

## Update

Обновить существующую информацию.

---

## Delete

Удалить запись.

---

## Search

Поиск по памяти.

---

## Get Context

Вернуть наиболее релевантный контекст для текущего запроса.

---

# Правила

- память никогда не изменяется напрямую LLM;
- все изменения проходят через сервис;
- каждая запись имеет источник;
- каждая запись имеет дату создания;
- каждая запись может иметь дату обновления;
- должна быть возможность архивирования.

---

# Будущее развитие

Позже будут добавлены:

- векторный поиск;
- оценка важности воспоминаний;
- автоматическая консолидация памяти;
- дедупликация;
- семантический поиск.

---

# Definition of Done

Memory Service считается готовым если:

- сохраняет данные;
- обновляет данные;
- удаляет данные;
- ищет данные;
- отдает релевантный контекст;
- покрыт тестами;
- документирован.

# LifeOS Agent System Overview

## Назначение

Этот документ описывает все основные подсистемы LifeOS Agent.

Он отвечает на вопрос:

> Из каких частей состоит система?

Каждый новый сервис должен быть отражен в этом документе.

---

# Общая схема

```
                    User
                      │
                      ▼
                 Telegram
                      │
                      ▼
           Conversation Engine
                      │
                      ▼
              Intent Router
                      │
     ┌────────────────┼────────────────┐
     ▼                ▼                ▼
 Memory Service   Planner Service   AI Service
     ▼                ▼                ▼
 Habits         Goals          Journal
     ▼                ▼                ▼
 Notifications  Analytics     Scheduler
                      │
                      ▼
                 PostgreSQL
```

---

# Основные сервисы

## AI Service

Отвечает за взаимодействие с языковой моделью.

Обязанности:

- генерация ответов;
- анализ текста;
- построение промптов;
- суммаризация.

---

## Memory Service

Хранение долгосрочной памяти пользователя.

Обязанности:

- факты;
- предпочтения;
- история;
- контекст.

---

## Planner Service

Планирование дня.

Обязанности:

- задачи;
- приоритеты;
- расписание.

---

## Goals Service

Работа с долгосрочными целями.

---

## Habits Service

Привычки пользователя.

---

## Journal Service

Дневник.

---

## Notifications Service

Напоминания.

---

## Analytics Service

Анализ активности пользователя.

---

## Scheduler Service

Запуск фоновых процессов.

---

## Telegram Service

Работа с Telegram Bot API.

---

# Главный принцип

Каждый сервис отвечает только за одну область.

Сервисы общаются между собой только через публичные интерфейсы.

Никаких прямых зависимостей между внутренней логикой сервисов быть не должно.

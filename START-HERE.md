# Запуск на новом компьютере

Короткая версия. Подробности — в `SETUP.md` после клонирования.

---

## Сначала один раз на СТАРОМ компьютере

Собрать секреты в зашифрованный архив:

```bash
bash lifeos-agent/scripts/secrets_bundle.sh pack
```

Появится `lifeos-secrets.enc` рядом с папкой проекта. Перенесите его на
новый компьютер — флешкой, облаком, чем угодно: **без мастер-пароля это
случайные байты**. Пароль запомните или положите в менеджер паролей,
восстановить его нельзя.

---

## Теперь на НОВОМ компьютере

### 1. Поставить три программы

- **Git** — <https://git-scm.com/download/win>
- **Python 3.11 или новее** — <https://www.python.org/downloads/>
  (при установке отметить галочку **Add Python to PATH**)
- **Claude Code** — <https://claude.com/claude-code>

### 2. Скачать проект

Открыть **Git Bash** и выполнить:

```bash
cd ~/Desktop
git clone https://github.com/gezhenko95-jpg/LifeOS-Agent.git
cd LifeOS-Agent
```

Спросит логин GitHub — репозиторий приватный, это нормально.

### 3. Поставить зависимости

```bash
cd lifeos-agent
pip install -e .[dev]
cd ..
```

### 4. Разложить секреты

Положить `lifeos-secrets.enc` **рядом** с папкой `LifeOS-Agent` (не
внутрь!), затем:

```bash
bash lifeos-agent/scripts/secrets_bundle.sh unpack
```

Спросит мастер-пароль.

### 5. Проверить, что всё на месте

```bash
python lifeos-agent/scripts/doctor.py
```

Скрипт сам скажет, чего не хватает и какой командой это чинится.
Зелёное — готово. Жёлтое — не страшно, часть необязательных фич
выключена. Красное — читайте подсказку под пунктом.

### 6. Начать работу

```bash
claude
```

И первым сообщением вставить:

```
Проект LifeOS Agent, я работаю с другого компьютера.

Прочитай HANDOFF.md и SETUP.md в корне репозитория — там состояние
проекта, что сделано, что осталось и накопленные грабли.

Затем выполни, не спрашивая разрешения:
  python lifeos-agent/scripts/doctor.py
  cd lifeos-agent && python -m pytest -q
  bash lifeos-agent/scripts/deploy.sh --check

Скажи, что видишь, и какая задача следующая по HANDOFF.
```

## Три вещи, которые сломают всё

**Не запускать бота локально с боевым токеном.** Telegram пускает только
одного потребителя `getUpdates` — домашний бот подерётся с серверным, и
прод свалится с `409 Conflict`. Нужен бот для проверок — заведите
отдельного в @BotFather.

**Не класть папку проекта на Google Drive.** Диск синхронизирует `.git/`
пофайлово и рвёт репозиторий. Синхронизация здесь — git.

**Не деплоить руками через ssh и tar.** Только
`bash lifeos-agent/scripts/deploy.sh`.

---

## Если деплой не нужен

Тогда ничего из секретов не обязательно: тесты идут на SQLite, у токенов
пустые значения по умолчанию. Достаточно шагов 1–3, и можно писать код.

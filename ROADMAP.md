## Сделано — домены (`app/`)

Модульный монолит, 10 доменов, каждый — `models/repository/service/
schemas` + REST-роутер в `app/api/`:

- **tasks** — подзадачи/эпики, комментарии, привязка к контакту/
  привычке/цели, «в работе», гвард закрытия при незавершённых подзадачах
- **habits** — стрики, шаблоны, напоминания
- **goals** — прогресс-бар (ползунок), привязка задач
- **memory** — журнал, семантический поиск (embeddings, без pgvector)
- **watchlist** — фильмы/книги (TMDb, Google Books)
- **digest** — дайджесты Telegram-каналов (скрейпинг `t.me/s/`, без юзербота)
- **finance** — транзакции, бюджет-рекомендации, долги + лог платежей + план рассрочки
- **crm** (contacts) — заметки/теги/nudge, комментарии, связанные задачи
- **mood** — трекер настроения (шкала 1-7)
- **assistant** — 4 персонажа бота с именами (фаза 2: память диалога,
  редкие незапланированные сообщения), разговорный intent CHAT
- **focus** — фокус-сессии/Pomodoro, опрос БД вместо `job_queue.run_once`

Плюс `rewards` (монеты, ежедневный визит), `shop` (магазин наград:
расходуемый баланс поверх заработанных монет, каталог-константы) и
`insights` (аналитика).

## Сделано — платформа

- FastAPI + PostgreSQL + SQLAlchemy async + Alembic, Docker Compose
  (`api`/`bot` — разные процессы)
- Telegram Bot (python-telegram-bot), `ConversationEngine` —
  телеграм-агностичный, rule-based + AI-фолбэк (OpenRouter)
- `/ui` — один HTML-файл, 4 скина (groovy/japan/pixel/graffiti),
  переключаемая акцентная тема; вёрстка «Панели» — вариант C владельца
  (потолок высоты + внутренний скролл у растущих списков, `designs/004`),
  задеплоено 26.08
- Аутентификация: `X-API-Token` на REST, `filters.User(owner)` на бота
  (single-user)
- Бэкапы БД ежедневно → Google Drive, восстановление проверено вручную
- 1368 тестов, `ruff`/`black` чисты
- `scripts/deploy.sh` — единственный способ деплоя, `--check` сверяет
  прод/гит/локаль

## В работе

- **Ферма + тамагочи + магазин (`specs/028`).** Все решения владельца
  закрыты (27.08), реализация разбита на фазы. **Фаза 1 — кошелёк и
  магазин — сделана:** монеты наконец расходуются (таблица
  `coin_transactions`, вариант (A) спеки — заработок по-прежнему
  считается из истории чек-инов, добавлено только вычитание сверху),
  витрина из семи товаров в трёх категориях на `/ui`. **Фазы 2-3 —
  ферма и питомец — не начаты**, купленное пока ни на что не влияет
  (сказано прямо в карточке магазина).

## Не начато / сознательно отложено

- Голосовой ввод — выключен намеренно (единственная статья расходов с
  заметной ценой), решение не меняется до вопроса монетизации
- Мультиарендность — сервер в Нидерландах, 152-ФЗ требует серверов в РФ
  для multi-tenant; открытая архитектурная проблема, см. `MULTIUSER.md`
- Десктоп-маскот тамагочи — отдельное Windows-приложение, после бэкенда
  питомца/фермы (`specs/028` явно выносит его за свои рамки)
- pgvector — не срочно, актуально при >1000 записей памяти (`AUDIT.md`, P-3)

## MVP (историческая цель, достигнута)

Первая рабочая версия умела: помнить пользователя, работать через
Telegram, хранить долгосрочную память, вести список задач, помогать
планировать день, делать ежедневный обзор, отвечать с учётом контекста.
Всё перечисленное реализовано и с тех пор далеко перерос исходный MVP.

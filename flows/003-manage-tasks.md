# Manage Tasks (list / complete / delete)

## Цель

Пользователь смотрит список активных задач, отмечает задачу выполненной или удаляет её — по названию, без id.

---

# Точка входа

Текстовое сообщение, распознанное Conversation Engine как `LIST_TASKS`,
`COMPLETE_TASK` или `DELETE_TASK` (см. `specs/003-conversation.md`).

---

# Последовательность — LIST_TASKS

1. Conversation Engine вызывает `TaskService.list_active_tasks(telegram_user_id)`.
2. Формирует нумерованный список названий (+ дата, если есть).
3. Если список пуст — сообщает, что активных задач нет.

---

# Последовательность — COMPLETE_TASK / DELETE_TASK

1. Conversation Engine получает из intent название-подстроку (например, «молоко»).
2. Вызывает `TaskService.complete_task_by_title` / `delete_task_by_title`.
3. Сервис ищет среди активных задач пользователя те, где подстрока встречается в `title` (без учета регистра).
4. Если найдена ровно одна — выполняет действие, возвращает задачу. Для `complete_task_by_title` — если задача повторяющаяся (`recurrence` задан), дополнительно создаётся следующее вхождение с датой, отсчитанной от исходного `due_date` (см. `specs/002-tasks.md`, Recurring Tasks); ответ пользователю получает пометку об этом.
5. Если не найдено — Conversation Engine сообщает «не нашёл такую задачу».
6. Если найдено несколько — Conversation Engine просит уточнить (в этой версии: берется первая по `created_at`, с пометкой в ответе, что совпадений было больше одного — уточнение по id доступно через REST API).

---

# Используемые сервисы

- Telegram
- Conversation
- Tasks

---

# Что читается

- активные задачи пользователя.

---

# Что записывается

- изменение статуса задачи (`completed`) либо удаление записи.

---

# Возможные ошибки

- задача не найдена;
- неоднозначное совпадение (несколько задач подходят под подстроку).

---

# Ожидаемый результат

Пользователь получает точный ответ: список, подтверждение выполнения или подтверждение удаления.

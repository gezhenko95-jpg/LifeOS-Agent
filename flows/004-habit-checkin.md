# Habit Check-in

## Цель

Пользователь заводит привычку и ежедневно отмечает её выполнение обычным
сообщением, без команд и id.

---

# Точка входа

Текстовое сообщение, распознанное Conversation Engine как `LIST_HABITS`
или `HABIT_DONE` (см. `specs/004-habits.md`), либо новое сообщение без
триггерных слов — тогда привычка не заводится автоматически: привычки
создаются только через REST API `/habits` (не каждое сообщение может
быть привычкой, в отличие от задач — иначе высок риск случайно завести
привычку из обычной фразы).

---

# Последовательность — LIST_HABITS

1. Conversation Engine вызывает `HabitService.list_active_habits`.
2. Для каждой привычки — `HabitService.get_streak`.
3. Формирует список: название + 🔥 стрик (если > 0).
4. Если привычек нет — сообщает об этом.

---

# Последовательность — HABIT_DONE

1. Conversation Engine получает подстроку названия из intent.
2. Вызывает `HabitService.mark_done_today(telegram_user_id, title_query)`.
3. Если привычка не найдена — «не нашёл такую привычку».
4. Если уже отмечена сегодня — сообщает без повторной записи в БД.
5. Иначе создаёт `HabitLog` на сегодня, показывает обновлённый стрик.

---

# Используемые сервисы

- Telegram
- Conversation
- Habits

---

# Что читается

- активные привычки пользователя;
- логи выполнения (для стрика).

---

# Что записывается

- новая привычка (через REST API);
- лог выполнения на сегодня (через чат).

---

# Возможные ошибки

- привычка не найдена по подстроке;
- несколько совпадений — берётся первая, остальные перечисляются
  (тот же приём, что у Tasks, см. `flows/003-manage-tasks.md`).

---

# Ожидаемый результат

Пользователь коротким сообщением поддерживает стрик привычки, видит
прогресс без необходимости открывать что-либо кроме Telegram.

# Personal Insights

## Цель

Показать закономерности в поведении пользователя, видимые только на
длинном горизонте (60 дней) — не сырые цифры (это уже делает дайджест),
а связи между ними.

---

# Точка входа

Два варианта:

**A. По запросу** — пользователь жмёт "📊 Инсайты" в главном меню.

**B. Фоново** — Scheduler, 1-е число месяца, `monthly_insights_hour`
(по умолчанию 12:00). Запускает `send_monthly_insights_job`.

---

# Последовательность

1. (Только B) Проверить `monthly_insights_enabled` и что сегодня 1-е
   число.
2. `InsightsService.build_findings(uid)` считает 0-4 находки:
   - продуктивный день недели (нужно ≥ 10 завершённых задач за 60 дней);
   - связь дневника и выполнения привычек (нужно ≥ 5 дней каждого типа);
   - дисциплина по срокам (нужно ≥ 5 завершённых задач с дедлайном);
   - рекорд серии привычки (нужна хотя бы одна привычка с логами).
3. `build_insights_text(findings)` собирает финальный текст.
4. (A) Telegram Service отправляет сообщение всегда, даже если находок
   нет ("пока маловато данных").
   (B) Telegram Service отправляет, только если есть хотя бы одна
   находка — тихий пропуск иначе, без сообщения.

---

# Используемые сервисы

- Insights (новый, `app/insights/`)
- Tasks, Habits, Memory (только чтение)
- Scheduler (для варианта B)
- Telegram

---

# Что читается

- завершённые задачи за 60 дней (`completed_at`, `due_date`);
- journal-записи за 60 дней (`created_at`);
- логи привычек (`habit_logs.completed_on`), все активные привычки.

---

# Что записывается

Ничего — фича только читает данные, никаких новых таблиц.

---

# Возможные ошибки

- Мало данных для конкретной находки → эта находка просто не
  показывается, остальные — как обычно;
- Совсем нет данных ни для одной находки → (A) фраза про нехватку
  данных, (B) сообщение не отправляется вовсе;
- `owner_telegram_user_id` не задан → фоновая job не отправляет ничего
  (как и остальные job'ы).

---

# Ожидаемый результат

Пользователь либо в любой момент, либо раз в месяц без напоминания с
его стороны, узнаёт что-то о своих паттернах, чего не видно из
повседневных брифингов и дайджестов.

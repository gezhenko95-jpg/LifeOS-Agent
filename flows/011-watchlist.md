# Flow: Watchlist (Фаза 1 Media Inbox, см. specs/010-media-inbox.md)

## Цель

Добавить фильм/книгу «на посмотреть» без трения (обычным текстом) и
управлять статусом парой тапов, как с привычками.

## Точка входа

- Свободный текст: «посмотреть фильм Дюна», «хочу прочитать книгу X».
- Кнопка «🎬 Посмотреть» в постоянном меню.

## Последовательность действий (добавление)

1. Пользователь пишет «посмотреть фильм Дюна».
2. `parse_intent` находит фразу «посмотреть фильм» → `Intent.
   ADD_WATCHLIST_ITEM`, `media_type=movie`, `title="Дюна"`.
3. `ConversationEngine._add_watchlist_item` → `WatchlistService.
   create_item(uid, "Дюна", media_type="movie")`.
4. Ответ: «Добавил в список: «Дюна» 🎬».

## Последовательность действий (список/статус)

1. Пользователь жмёт «🎬 Посмотреть».
2. `handlers.py` → `WatchlistService.list_active_items(uid)` →
   `build_watchlist_message` → сообщение со строками + ✅/🗑 под каждой +
   «🎲 Порекомендуй» в конце.
3. Тап ✅ → `callbacks.py` → `WatchlistService.mark_done(item_id)` →
   `status=done`, `completed_at=now()` → сообщение обновляется без этой
   строки.
4. Тап 🗑 → `WatchlistService.delete_item(item_id)` → строка исчезает.
5. Тап «🎲 Порекомендуй» → `WatchlistService.pick_recommendation(uid,
   ai_client)` → короткое сообщение с выбором.

## Какие сервисы участвуют

`WatchlistService` (новый), `ConversationEngine` (расширен), AI-клиент
(только для рекомендации, опционально).

## Какие данные читаются/записываются

Читается/пишется только `watchlist_items` конкретного пользователя.

## Возможные ошибки

- Пустой заголовок после вырезания фразы («посмотреть фильм» без
  названия) — не создаём запись, отвечаем "Что посмотреть-то?" (по
  аналогии с пустой задачей).
- Список пуст при нажатии «🎲 Порекомендуй» — "Смотреть пока нечего."
- AI недоступен при рекомендации — тихий фолбэк на случайный выбор без
  комментария.

## Ожидаемый результат

Запись появляется в списке сразу после текстового сообщения, статус
меняется в один тап, без повторного ввода данных.

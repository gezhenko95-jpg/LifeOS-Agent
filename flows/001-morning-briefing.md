# Morning Briefing

> **Текущая реализация:** шаг «AI формирует брифинг» пока заменён шаблонной
> сборкой текста из Tasks + Memory (`app/scheduler/briefing.py`), без вызова
> LLM. Когда появится AI Service, эта функция заменится на вызов AI с тем же
> собранным контекстом — остальной флоу не меняется.

## Цель

Каждое утро LifeOS самостоятельно помогает пользователю начать день.

Это не список задач.

Это персональный брифинг.

---

# Точка входа

Запланированное время (например 08:00).

Scheduler запускает сценарий.

---

# Последовательность

1. Проверить, что пользователь не отключил утренний брифинг.

2. Получить информацию из Memory Service:
   - предпочтения;
   - долгосрочные цели;
   - текущие проекты.

3. Получить данные из Planner:
   - задачи на сегодня;
   - просроченные задачи;
   - важные дедлайны.

4. Получить данные из Calendar.

5. Получить данные из Habits:
   - какие привычки сегодня;
   - серия выполнения;
   - пропуски.

6. Получить данные из Journal:
   - была ли вечерняя рефлексия;
   - есть ли незавершенные мысли.

7. Передать собранный контекст AI Service.

8. AI формирует утренний брифинг.

9. Telegram Service отправляет сообщение пользователю.

---

# Используемые сервисы

- Scheduler
- Memory
- Planner
- Calendar
- Habits
- Journal
- AI
- Telegram

---

# Что читается

- память;
- задачи;
- календарь;
- привычки;
- дневник.

---

# Что записывается

- факт отправки брифинга;
- время отправки;
- статус доставки.

---

# Возможные ошибки

- пользователь спит (в будущем);
- Telegram недоступен;
- AI недоступен;
- отсутствуют данные.

Система должна корректно обработать все ошибки.

---

# Ожидаемый результат

Пользователь получает короткий, полезный и персонализированный брифинг, который помогает начать день, а не просто список задач.

# User Flows

В этой папке описываются пользовательские сценарии LifeOS Agent.

## Что такое User Flow

User Flow — это пошаговое описание того, что происходит с момента действия пользователя до получения результата.

Мы проектируем поведение системы до написания кода.

---

## Формат

Каждый сценарий хранится в отдельном файле.

Примеры:

```
flows/
├── 001-morning-briefing.md
├── 002-add-task.md
├── 003-journal.md
├── 004-goal.md
```

---

## Каждый сценарий должен содержать

- Цель
- Точку входа
- Последовательность действий
- Какие сервисы участвуют
- Какие данные читаются
- Какие данные записываются
- Возможные ошибки
- Ожидаемый результат

---

## Главное правило

Если пользовательский сценарий не описан — его нельзя реализовывать.

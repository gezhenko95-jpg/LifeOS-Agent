# Proactive Engagement (проактивные вопросы)

## Цель

LifeOS сам инициирует диалог 3 раза в день, чтобы постепенно наполнять
профиль пользователя (цели, привычки, проекты, предпочтения) — не
дожидаясь, пока пользователь сам всё это внесёт через `/ui` или явные
команды.

---

# Точка входа

Запланированное время, 3 слота в день (см. `app/core/config.py`):
утро (10:30 по умолчанию), день (14:00), вечер (19:00). Scheduler
запускает `send_proactive_prompt_job` (одно и то же тело job для всех
трёх слотов, см. `specs/006-proactive-engagement.md`).

---

# Последовательность (отправка вопроса)

1. Проверить, что `owner_telegram_user_id` задан и `proactive_prompts_enabled`.
2. Проверить, что AI Service доступен (`openrouter_api_key` задан) — без
   него отвечать на свободный текст всё равно нечем.
3. `PendingPromptService.pick_and_open`:
   - получить из Goals/Habits/Memory, чего у пользователя ещё нет
     (gap-detection, по приоритету: цели → привычки → проекты →
     предпочтения → "как дела" в остальных случаях);
   - выбрать конкретную формулировку вопроса из банка (`questions.py`);
   - записать вопрос как "открытый" (`pending_prompts`, перезаписывает
     предыдущий неотвеченный).
4. Telegram Service отправляет вопрос пользователю.

---

# Последовательность (ответ пользователя)

1. Пользователь отвечает обычным текстовым сообщением (без специального
   синтаксиса — просто как есть).
2. `ConversationEngine.handle_message`: rule-based парсер не узнаёт
   ключевых слов → `Intent.ADD_TASK`.
3. Есть открытый вопрос → AI Service разбирает ответ в контексте вопроса
   (`extract_prompt_answer`).
4. Если ответ связан с вопросом:
   - описывает цель → `GoalService.create_goal`;
   - описывает привычку → `HabitService.create_habit`;
   - это факт/предпочтение/проект → `MemoryService.save`.
   Вопрос закрывается, пользователь получает короткое подтверждение.
5. Если ответ не связан с вопросом (например, это на самом деле новая
   задача) — вопрос остаётся открытым, а сообщение обрабатывается как
   обычно (скорее всего — создаётся новая задача).

---

# Используемые сервисы

- Scheduler
- Goals, Habits, Memory (для gap-detection и для сохранения ответа)
- AI (разбор ответа)
- Conversation Engine
- Telegram

---

# Что читается

- активные цели, привычки;
- записи памяти типа `project`/`preference`;
- текущий открытый вопрос (`pending_prompts`).

---

# Что записывается

- новый/обновлённый открытый вопрос (при отправке);
- новая цель/привычка/запись памяти (при успешном разборе ответа);
- закрытие вопроса (`pending_prompts` очищается).

---

# Возможные ошибки

- AI недоступен при разборе ответа → ответ считается "не связан с
  вопросом" (тот же путь, что и настоящий `unrelated`), вопрос остаётся
  открытым, сообщение обрабатывается как обычный текст;
- AI вернул action, но без обязательного поля (например, `create_goal`
  без `title`) → аналогично, вопрос не теряется;
- пользователь никак не отвечает → вопрос просто перезаписывается
  следующим по расписанию, без ошибки.

---

# Ожидаемый результат

Пользователь получает 3 коротких вопроса в день, отвечает свободным
текстом — и данные о нём (цели/привычки/проекты/предпочтения)
пополняются сами, без отдельного похода в `/ui`.

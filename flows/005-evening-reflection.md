# Evening Reflection

## Цель

Вечером LifeOS напоминает пользователю подвести итоги дня и коротко
зафиксировать выводы — без сложного диалога, одним сообщением.

---

# Упрощение относительно PROJECT.md (осознанное решение)

PROJECT.md описывает рефлексию как диалог: «Agent помогает провести
рефлексию, запоминает выводы». Полноценный многошаговый диалог требует
хранить состояние «жду ответ пользователя на рефлексию» — отдельный
стейт-машин на пользователя, таймауты, обработку случая, когда пользователь
вместо ответа написал новую задачу. Это заметно сложнее уже работающих
частей системы, а выигрыш небольшой (в системе один пользователь).

Вместо этого: вечернее напоминание — обычное сообщение с примером фразы.
Пользователь отвечает **в любой момент**, отдельным сообщением с триггерным
словом («дневник:», «рефлексия:», «итоги дня:») — это не привязано к
конкретному напоминанию и не требует состояния диалога (ADR-004).

---

# Точка входа

Запланированное время (например 21:00). Scheduler запускает
`send_evening_reflection_job` (тот же `JobQueue`, что у Morning Briefing,
см. `flows/001-morning-briefing.md`).

---

# Последовательность — напоминание

1. Проверить `evening_reflection_enabled` и `owner_telegram_user_id`
   (см. `app/core/config.py`) — если не заданы, джоба не регистрируется.
2. Отправить статичный текст-подсказку с примером фразы.

---

# Последовательность — запись рефлексии

1. Пользователь пишет сообщение, начинающееся с «дневник», «рефлексия»
   или «итоги дня» (Conversation Engine, см. `specs/003-conversation.md`,
   `Intent.JOURNAL_ENTRY`).
2. Остаток сообщения (после двоеточия/пробела) — текст записи.
3. `MemoryService.save(type=JOURNAL, content=..., source="telegram")`.
4. Ответ пользователю: «Записал в дневник».

---

# Используемые сервисы

- Scheduler
- Telegram
- Conversation
- Memory

---

# Что читается

- ничего для отправки напоминания (статичный текст).

---

# Что записывается

- запись в Memory (`type=journal`) при ответе пользователя.

---

# Возможные ошибки

- пользователь не ответил вообще — ничего не происходит, это нормально;
- пустой текст после триггерного слова — просим переформулировать
  (как у Tasks/Habits при пустом названии).

---

# Ожидаемый результат

Пользователь получает вечернее напоминание и может в одно сообщение
зафиксировать итог дня, который попадает в долгосрочную память.
